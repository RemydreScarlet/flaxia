# Flaxia License Overview

Flaxia is an open-source social networking project released under the GNU Affero General Public License v3.0 (AGPL-3.0).

Anyone is free to view, use, modify, and redistribute Flaxia's code; however, due to the nature of the AGPL, the following obligations apply.

## Requirements of AGPL-3.0

The AGPL is a derivative of the GPL that imposes strong source code disclosure requirements, particularly for use over a network.

### 1. Obligation to Share Modified Code

If you modify Flaxia and host it as a service, you must publicly release the source code, including your modifications.

### 2. Application to Network Access

The AGPL also applies to "server-side code."

If you modify Flaxia and offer it as a web service, you must provide a way for users interacting with it over a network to obtain the complete source code.

### 3. Copyleft / Inheritance for Derivative Works

Any derivative work based on Flaxia must also be released under the same AGPL-3.0 license.

## Handling of User-Posted Content

Since Flaxia is a social network, content posted by users (such as images, text, music, games, and HTML5 apps) is treated separately from the license of the Flaxia core system itself.

* Copyright of posts belongs to the respective users.
* Terms of use for posts follow the Flaxia Terms of Service.
* User posts are not covered by the AGPL.
* Redistribution rights for posts are decided by the user.

Flaxia can be used for commercial purposes.

However, in accordance with the AGPL obligations, you must ensure the following:
```
    Disclosure of modified code
    Provision of source code to network users
```
