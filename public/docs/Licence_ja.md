# Flaxia License Overview

Flaxia は GNU Affero General Public License v3.0 (AGPL-3.0) の下で公開されているオープンソース SNS プロジェクトです。
Flaxia のコードは誰でも閲覧・利用・改変・再配布できますが、AGPL の特性上、以下の義務が発生します。
## AGPL-3.0 が要求すること

AGPL は GPL の派生であり、特に ネットワーク越しの利用 に強い公開義務を課します。

### 1. 改変したコードの公開義務

Flaxia を改変してサービスとして公開する場合、
改変部分を含むソースコードを公開する必要があります。

### 2. ネットワーク越しの利用にも適用
AGPL は「サーバー側で動くコード」にも適用されます。
Flaxia を改変して Web サービスとして提供する場合、
利用者がソースコードを取得できる手段を提供する必要があります。

### 3. 派生物のライセンス継承

Flaxia をベースにした派生物は、
同じ AGPL-3.0 ライセンスで公開する必要があります。

## 投稿コンテンツの扱い

Flaxia は SNS であり、ユーザーが投稿するコンテンツ（画像・文章・音楽・ゲーム・HTML5アプリなど）は
Flaxia本体のライセンスとは別扱いです。

- 投稿の著作権はユーザーに帰属します
- 投稿の利用条件は Flaxia 利用規約に従います
- 投稿は AGPL の対象ではありません
- 投稿の再配布権はユーザーが決めます

## 商用利用について

Flaxia は商用利用可能です。
ただし AGPL の義務により、以下が必要です：
```
    改変したコードの公開
    ネットワーク越しの利用者へのソースコード提供
    派生物の AGPL ライセンス継承
```
Flaxia を SaaS として提供する場合も同様です。
