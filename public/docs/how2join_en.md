# Joining Flaxia

## Anyone Can Join Flaxia

Flaxia aims to be more than just another social network—it aspires to be a **playground for users**.

Because of this, Flaxia is constantly evolving and improving, and we welcome proposals and contributions from the community.

There are many ways to participate in Flaxia.

## Contributing Code

[Flaxia](https://github.com/TeamFlaxia/flaxia) is open-source software released under the AGPL. It is built primarily using Cloudflare Workers, Pages, D1, and R2, and is written in TypeScript.

* Bug fixes
* New feature proposals
* UI/UX improvements
* Documentation updates
* Performance enhancements

All of these are welcome! Non-programmers shouldn't hesitate either—feel free to open Issues or submit Pull Requests anytime.

## Joining as a Creator

While Flaxia is a microblogging platform, it supports a wide variety of file attachments:

* HTML games
* Artwork
* Videos
* Audio / Music
* PDFs

...and much more. Flaxia supports various forms of expression, so feel free to share your work!

## Joining as a Tester

With new features being added frequently, simply trying things out and letting us know what you notice is a huge help.

* Bug reports
* Pointing out usability issues
* Sharing improvement ideas
* Feedback on new features

Every bit of feedback helps the development team.

## Joining the Community

Flaxia places a high value on user interaction.

* Posting with hashtags
* Simply using the platform as a social network

...and more.

All of these are wonderful ways to participate.

## Flaxia Welcomes Your Participation

Flaxia is an "open social network where anyone can join."

Whether you write code, post content, or share your feedback, Flaxia warmly welcomes your contribution.

Let’s grow Flaxia together!
